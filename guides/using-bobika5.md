# Using BobikA5

BobikA5 is an untethered bypass tool for compatible iOS versions from 7.0 to 10.3.4

::: warning
While BobikA5 does indeed work, it's not recommended to use it. Its device/iOS version support is extremely spotty, and even (allegedly) supported devices have had trouble getting activated with the tool in the past.

The developer has also been known to steal code and break licenses on other tools. When possible, use <a href="using-hacktiv8.html">hacktiv8</a> instead.
:::

## Requirements

A computer running Windows with the [BobikA5](https://github.com/bablaerrr/bobikA5/releases/latest/download/net48.zip) installed.

## Step-by-Step Guide

### Running BobikA5

1. Download and extract BobikA5 to an easily accessible location on your computer. 
  - Install drivers if needed using the `install this if u dont have drivers.msi` file.
2. Run `BobikA5.exe`
3. Connect your device to your computer with a USB cable.
4. Once connected, click the `Check Device Compatibility` button.
  - If your device comes up as incompatible (very common), try [deleting setup.app](deleting-setupapp.html) to bypass your device on your current iOS version, or update and proceed to [using hacktiv8](using-hacktiv8.html) to bypass your device.
4. Click the `Activate Your Device` button and wait for the device to reboot twice.
